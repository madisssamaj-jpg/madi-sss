### 4.2 Google Consent Mode v2 Architecture

Before the visitor makes a selection on the cookie banner, Consent Mode v2 initializes with strict denials:

```javascript
window.dataLayer = window.dataLayer || [];
function gtag(){dataLayer.push(arguments);}

// 1. Strict default denial before user choice
gtag('consent', 'default', {
  'ad_storage': 'denied',
  'analytics_storage': 'denied',
  'ad_user_data': 'denied',
  'ad_personalization': 'denied',
  'wait_for_update': 500
});

// 2. Anonymization flags mandatory
gtag('set', 'anonymize_ip', true);
gtag('set', 'allow_google_signals', false);
```

When the user clicks an option:
- **Accept All**: Updates `analytics_storage: 'granted'`, `ad_storage: 'granted'`.
- **Essential Only / Reject**: Keeps all categories `denied`. No network calls dispatched to external tracking servers.

### 4.3 Standard Non-PII Conversion Events

All custom events transmit only categorical IDs and slugs. **Zero form inputs or identities are collected:**

| Event Trigger | Event Name in GTM | Safe Payload Parameters | Prohibited Parameters (Strictly Checked) |
| :--- | :--- | :--- | :--- |
| Public page load | `page_view` | `page_path`, `page_title`, `lang` (`ne`\|`en`) | Query strings containing names or numbers |
| Read membership page | `view_membership` | `membership_tier` (`general`\|`life`) | Any user identifier |
| Open membership form | `begin_membership_application` | `step: 1`, `lang` | Form input values |
| Submit membership form | `submit_membership_application` | `status: "success"`, `application_type` | Applicant name, phone, email, citizenship |
| Send feedback / inquiry | `submit_feedback` | `topic_category` (`health`\|`culture`\|`other`) | Message body, sender name, contact info |
| Download public report | `download_document` | `document_slug`, `fiscal_year` | Downloader IP address or session identity |

### 4.4 Quality Assurance & Pre-Activation Test Plan

1. **Local Build Test**: Confirm `npm test` runs with 100% pass rate and that layout bundles contain no external script tags.
2. **GTM Tag Assistant Preview**: Verify in sandbox that `ad_user_data` and `analytics_storage` are strictly `denied` on initial page load.
3. **Payload Inspection**: Use browser devtools network monitor to confirm that outgoing requests to Google or Meta contain no query parameters matching `email`, `phone`, `name`, `nagrikta`, or `citizenship`.
4. **Admin Route Exemption**: Confirm tracking script loader explicitly skips any URL beginning with `/admin` or `/api`.
5. **Emergency Kill-Switch**: Setting `NEXT_PUBLIC_ANALYTICS_ENABLED=false` immediately terminates all tracking script injection without requiring a code rebuild.
